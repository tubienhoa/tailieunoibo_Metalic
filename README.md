# Hệ Thống Rà Soát Tuân Thủ Pháp Lý & Thuế Doanh Nghiệp (Streamlit App)

Ứng dụng Web Dashboard rà soát tuân thủ 84 mục dành cho kế toán, nhân sự và ban điều hành, kết nối trực tiếp với Google Sheets.

## 🚀 Hướng Dẫn Đưa Lên GitHub & Triển Khai Streamlit Cloud

### Bước 1: Đưa mã nguồn lên GitHub
1. Tạo một Repository mới trên GitHub (ví dụ đặt tên: `compliance-checklist-app`).
2. Tải các file trong thư mục này lên Repo (bao gồm: `app.py`, `requirements.txt`, `README.md`).
3. Nhấn **Commit changes**.

### Bước 2: Triển khai trên Streamlit Cloud
1. Truy cập [share.streamlit.io](https://share.streamlit.io/) và đăng nhập bằng tài khoản GitHub.
2. Nhấn nút **Create app** (hoặc **New app**).
3. Chọn Repository vừa tạo: `compliance-checklist-app`.
4. Nhánh (Branch): `main`.
5. Tệp chính (Main file path): `app.py`.
6. Nhấn **Deploy!**. Hệ thống sẽ tự động cài đặt thư viện và chạy trang web của bạn trong vòng 1-2 phút.

---
**Nguồn dữ liệu:** Đồng bộ trực tiếp thời gian thực qua link Google Sheets CSV.
